# CtrlSpeak 0.8.6 control centre polish

- Midnight Signal is the only window and widget tree created for the control
  centre. Shared settings and update callbacks stay; the old UI is gone.
- The stable updater only installs a newer version. Old explicit-downgrade
  journals are not installable. Settings, signed differential/full download,
  and recovery from a failed new startup are unchanged.
- Updates separates download controls from diagnostics, starts with the right
  button states and ignores stale check events. System shows microphone, CUDA,
  and model status beside the controls. Keyboard navigation respects editors
  and lists, and the panel can be resized smaller.
- Dictation modes, provider routing, correction rules and the API are unchanged.

`python scripts/verify_control_centre.py` verifies real Tk first-open/reopen
mapping, one-window construction, editor navigation and forward-update controls
without opening the installed desktop app or contacting the gateway.
