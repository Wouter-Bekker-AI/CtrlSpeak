# CtrlSpeak 0.8.5 maintenance release

Target tag: `v0.8.5`. This release is for code, dependency and documentation
cleanup, not a change to how the product works.

## Audit and changes

| Finding | Action and evidence |
| --- | --- |
| Three old waveform functions were redefined later in the same module | Removed the unreachable definitions in `utils/gui.py`; the retained Midnight Signal functions are the existing callers' only implementation. |
| The old looping PortAudio cue and its animation buffers had no live caller | Removed the loop, state, WAV loader, stop-event shim and tests that exercised only the retired path. The finite cue tests and native sink/PortAudio arbitration tests remain. |
| `loading.wav` was still copied into current packages | Excluded from both maintained build variants. The source asset and historical specs remain for old build references. |
| OpenCV was installed but not imported; linters were installed as desktop dependencies | Removed OpenCV and moved developer tooling to `requirements-dev.txt`. CI installs its test runner explicitly. Active media, audio, input, HTTP and model dependencies remain. |
| A failed patch-tool download produced cascading Windows test failures | Split pinned-tool provisioning from pytest so CI stops at the actual failed dependency. Pin, license, signature and runtime update logic are unchanged. |
| Unused helpers, imports and state across the desktop and tools | Checked tracked source, tests, build specs and dynamic entry points; removed the unused items. Kept deliberate binary-availability imports in the packaged DNS smoke and Hugging Face Xet probe. |
| README and live guides mixed current instructions with older deployment assumptions | Replaced repeated release history with current instructions and links to historical records. Corrected FLAC, RMS meter, Live, audit privacy, signed patch assets and coordinated deployment guidance. Added a documentation index and code map. |
| GitHub's default branch was an old, divergent snapshot | Use `stable` for the current release source and keep historical `main`, version branches, tags and releases intact. |
| Untouched Windows baseline failed one shutdown-budget assertion | The observed join budget was 0.010000000009313226 s against a 0.01 s assertion. Allow clock-subtraction rounding in the test only; runtime deadlines remain unchanged. |

## Preserved behavior

Existing Hold/Hands-free/Live gestures, microphone meter choices, cue volume,
terminal/AnyDesk text safety, corrections, optional GPU S1 and format selection,
provider cascades, lossless audio, authentication, API and helper contracts,
settings migrations, signed patch/full install, and 0.7.7 rollback. The
service/helper changes are version metadata only. No new feature or protocol
version is introduced.

The signed fleet workflow is the same rollout path as 0.8.4. It does not
restart Hermes. Windows desktop installation remains a user action.
